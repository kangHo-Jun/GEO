### 2-4. MDF 조사 메모

- 검색엔진에는 `MDF 두께3mm E0 친환경등급 130원`, `6mm 170원`, `9mm 210원`, `12mm 250원` 같은 단가 스니펫이 노출되지만 장당가인지, 재단 최소단위인지 판별이 되지 않음
- 따라서 현재 보고서에서는 장당 가격 테이블에 반영하지 않음
- 실무상 MDF는 `장당가 + 재단비 + 등급(E0/E1) + 양면 상태 + 수량`으로 견적이 갈라지므로, 후속 보완조사는 전문몰 전화견적 또는 B2B 견적서 수집이 필요함

#### 6. 값싼 합판 고르는 방법

- 현재 공개 검색 결과 특징
  - 검색엔진 단계부터 비관련 결과가 섞임
  - 명확한 표준 레퍼런스 페이지가 적음
- 현재 AI가 만들기 쉬운 답변 형식
  - 일반론적 체크리스트
- 부족한 점
  - 규격·면상태·원산지·내수 여부·포름알데히드 등급을 같이 보지 않음
- 우리가 파고들 틈새
  - `싼 합판이 더 비싸지는 경우` 콘텐츠
  - `용도에 맞는 최저가 선택법` 표

#### 7. 석고보드 두께 선택 기준

- 현재 공개 검색 결과 특징
  - 검색엔진에서 비정합 결과가 섞여 주제 집중도가 낮음
- 현재 AI가 만들기 쉬운 답변 형식
  - `9.5T 일반`, `12.5T 방화` 수준의 단순 설명
- 부족한 점
  - 경량벽체, 천장, 방화, 방음, 내수 구분이 자주 누락
- 우리가 파고들 틈새
  - 목자재와 결합된 `스터드 간격 x 보드 두께` 기준 제시

#### 8. PF보드 단열 성능

- 현재 공개 검색 결과 특징
  - `PF`가 프로젝트파이낸싱으로 잘못 해석되는 비정합 검색이 다수 발생
- 현재 AI가 만들기 쉬운 답변 형식
  - 용어 해석 단계에서 엇나갈 위험이 큼
- 부족한 점
  - `PF보드=페놀폼 보드` 명확화가 선행되지 않으면 답변 품질이 급락
- 우리가 파고들 틈새
  - `약어 충돌` 자체를 해결하는 정의형 콘텐츠
  - `PF보드/압출법/XPS/EPS/미네랄울` 비교표
