# GEOFlow 사용설명서

## 1. 시작하기 전에 — Docker 실행

GEOFlow는 Docker 위에서 동작합니다. 브라우저를 열기 전에 반드시 Docker를 먼저 켜야 합니다.

### 1-1. 터미널 열기

Mac의 경우 `Finder → 응용 프로그램 → 유틸리티 → 터미널` 을 실행합니다.

### 1-2. GEOFlow 폴더로 이동

```
cd /프로젝트/GEO/GEOFlow
```

### 1-3. Docker 컨테이너 시작

```
docker compose up -d
```

아래와 같이 ✔ 표시가 7개 나오면 정상입니다.

```
✔ Container geoflow-redis      Running
✔ Container geoflow-postgres   Healthy
✔ Container geoflow-queue      Running
✔ Container geoflow-scheduler  Running
✔ Container geoflow-reverb     Running
✔ Container geoflow-app        Running
✔ Container geoflow-init       Exited
```

> ⚠️ `geoflow-init`이 `Exited` 상태인 것은 정상입니다. 초기화 작업이 끝나면 자동으로 종료됩니다.

---

## 2. 사이트 접속 확인

브라우저(Chrome, Safari 등)를 열고 아래 주소를 입력합니다.

```
http://localhost:18080
```

**"건축자재 전문 정보"** 메인 화면이 보이면 정상입니다.

---

## 3. 관리자 페이지 로그인

### 3-1. 관리자 페이지 주소

브라우저 주소창에 아래를 입력합니다.

```
http://localhost:18080/geo_admin
```

### 3-2. 로그인 정보 입력

| 항목 | 값 |
|------|-----|
| 아이디 | `admin` |
| 비밀번호 | `password` |

입력 후 **로그인** 버튼을 클릭합니다.

---

## 4. 종료하기

작업이 끝나면 터미널에서 아래 명령으로 Docker를 종료합니다.

```
docker compose down
```

> Docker를 종료하지 않으면 컴퓨터 자원을 계속 사용하므로, 작업 후에는 꼭 종료해주세요.

---

## 5. 자주 발생하는 문제

### 브라우저에서 404 Not Found 오류가 날 때

→ Docker가 실행 중인지 확인하세요. `docker compose up -d` 를 다시 실행해보세요.

### `/admin` 으로 접속했는데 404가 날 때

→ GEOFlow의 관리자 경로는 `/admin` 이 아닌 `/geo_admin` 입니다.  
올바른 주소: `http://localhost:18080/geo_admin`

### `no configuration file provided` 오류가 날 때

→ GEOFlow 폴더 안에서 명령을 실행해야 합니다.  
`cd /프로젝트/GEO/GEOFlow` 로 이동 후 다시 시도하세요.
